# Fnord Prefect

<p class="article-meta">Tome IV · Abstract Horror / BLOCK 2 - ABSTRACT HORROR / SECTION A - HORRORISM / CHAPTER ONE - METHOD · May 27, 2014</p>

[Read the original post ↗](http://www.xenosystems.net/fnord-prefect/){ .article-source }

Scott Alexander shows an acute
[appreciation](https://slatestarcodex.com/2014/05/24/nydwracus-fnords/)
for Nydwracu’s Fnord
[hunting](https://nithgrim.wordpress.com/2014/05/21/fnords/)
(my
[own](https://www.xenosystems.net/scrap-note-13/) was
far too cursory). It’s rare to see the innovation of a
*method* (with a purpose), and it’s something more
noteworthy than any but the most exceptional *idea*.

Someone with the requisite technical skills should implement this
method in convenient software. As a quick-and-dirty way to
excavate real messages, it’s hard to beat.
