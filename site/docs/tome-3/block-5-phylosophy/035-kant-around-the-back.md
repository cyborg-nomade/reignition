# Kant around the back

<p class="article-meta">Tome III · Xenosystems / BLOCK 5 - PHYLOSOPHY · December 29, 2016</p>

[Read the original post ↗](http://www.uf-blog.net/kant-around-the-back/){ .article-source }

Schmidhuber
[exemplifies](https://www.inverse.com/article/25521-juergen-schmidhuber-ai-consciousness)
the path, while talking about robots:

*One important thing about consciousness is that the agent, as it is
interacting with the world, will notice that there is one thing that
is always present as it is interacting with the world — which is the
agent itself.*

(Some room for quibbling, but it doesn’t get serious. This is where
transcendental subjectivity comes from.)
