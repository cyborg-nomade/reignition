# Astro-Humanism

<p class="article-meta">Tome III · Xenosystems / BLOCK 5 - PHYLOSOPHY · November 27, 2015</p>

[Read the original post ↗](http://www.uf-blog.net/astro-humanism/){ .article-source }

The final symbol of our species’ concern for itself is the rescue of a
stranded astronaut. (First
[Gravity](https://www.imdb.com/title/tt1454468/), now
[The Martian](https://www.imdb.com/title/tt3659388/?ref_=nv_sr_1), both classics of the Space-Cinema-Sino-US-Detente Complex.)  
[![Martian00](https://www.uf-blog.net/wp-content/uploads/2015/11/Martian00.jpg)](https://www.uf-blog.net/wp-content/uploads/2015/11/Martian00.jpg)  
There are narrative problems you could fly a starship through (with
missing robots at the top of the list). It doesn’t matter.

Cinema is made for space (the outside of the terrestrial gravity well,
not geometry), and the soul-crushing silence of the void annihilates
all plot quibbles — if you get sucked out into it.  
[![Martian01](https://www.uf-blog.net/wp-content/uploads/2015/11/Martian01-e1448634684720.jpg)](https://www.uf-blog.net/wp-content/uploads/2015/11/Martian01-e1448634684720.jpg)  
*UF* finds it impossible to watch these things without
thinking:
*The only true wretchedness is to not be an astronaut*. It’s
probably the same strange religion we started with, but from the other
side.
