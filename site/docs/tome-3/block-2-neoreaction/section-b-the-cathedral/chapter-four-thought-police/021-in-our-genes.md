# In Our Genes

<p class="article-meta">Tome III · Xenosystems / BLOCK 2 - NEOREACTION / SECTION B - THE CATHEDRAL / CHAPTER FOUR - THOUGHT POLICE · September 10, 2014</p>

[Read the original post ↗](http://www.xenosystems.net/in-our-genes/){ .article-source }

That there is a genetic contribution to
~~IQ~~ ‘cognitive
performance’ has been theoretically obvious for as long as these
concepts have existed. Now it has been empirically
[confirmed](https://www.pnas.org/content/early/2014/09/05/1404623111.long). The basic argument should be over now (but I’m not holding my
breath).

As this type of information becomes a flood, the
[dike](https://www.amren.com/news/2014/02/the-unfortunately-innate-nature-of-intelligence/)
of ideologically-motivated obscurantism has — eventually — to
break. Watch for the smart rats to start jumping off first.
