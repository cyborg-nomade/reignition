# Dark Humor

<p class="article-meta">Tome III · Xenosystems / BLOCK 2 - NEOREACTION / SECTION B - THE CATHEDRAL / CHAPTER SIX - A DARK TWIN · December 7, 2013</p>

[Read the original post ↗](http://www.xenosystems.net/dark-humor/){ .article-source }

Slavic humor has a deserved reputation for philosophical
penetration; routing around idealistic cant and crime-stop
obstacles to deride totalitarianism. This recent example (via
@MiriamElder, at #Russianhumor) is superb:

“Why won’t there ever be a revolution in America?”  
“Because there aren’t any American embassies in America.”
