# The Polarizer

<p class="article-meta">Tome III · Xenosystems / BLOCK 2 - NEOREACTION / SECTION C - DEMOCRACY AND DEMOTISM / CHAPTER ONE - SYSTEMATIC FEATURES · December 3, 2015</p>

[Read the original post ↗](http://www.uf-blog.net/the-polarizer/){ .article-source }

Considered solely in its basic cybernetic function, as a bi-polar
homeostat, the power of American democracy is extraordinary.
Binary oscillation is what it needs to work, so that is what it
produces, absorbing all variation into its structured contest.
Animal totems almost insultingly attest to the mobilization of
archaic tribal instinct, and to the implicit meaninglessness of
the one difference it permits. There is nothing, it
[seems](https://pjmedia.com/richardfernandez/2015/12/3/san-bernardino-straight), that can escape it:

*Perhaps it is fair to say that it is now impossible to commit a
simple murder or even an outrage as an individual act. It’s all
imbued with meaning, almost as if the conflict between the cops
and the perps were overshadowed by a far larger fight: Right
versus Left in America.*

There’s an unmistakable
[trend](https://www.uf-blog.net/polarization/) to
intensification (more
[here](https://www.pewresearch.org/packages/political-polarization/)). Does that strengthen the mechanism, or steer it into crisis?

A social *controlled fission* device of this scale and
complexity is unprecedented in history. It began as an experiment,
and is still undergoing dynamic evolution. How stable is the
stabilizer? It’s unlikely that anybody understands it well enough
to do better than guess.
