The radical
[repolarization](https://en.wikipedia.org/wiki/Political_parties_in_the_United_States)
of the party system within an Anglophone democracy is a rare
event. To find persuasive precedent for what is happening today,
it is arguably necessary to return all the way to the mid-19th
century and the emergence of the Republican Party during the Civil
War era. It’s only natural, then, that their should be an unusual
level of agitation about developments (though this description
risks — very seriously — putting the cart before the horse).

2016 is set to be a year for the history books.
