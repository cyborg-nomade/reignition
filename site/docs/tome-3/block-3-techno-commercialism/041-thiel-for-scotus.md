It’s 2016, so suddenly it’s imaginable we could witness the
[Singularity](https://thehill.com/blogs/ballot-box/presidential-races/296082-report-trump-wants-paypal-co-founder-on-scotus)
within a few years. It’s tempting to say (even if the rumors are true)
that he has better things to do, but he’s not actually
[Musking](https://waitbutwhy.com/2015/05/elon-musk-the-worlds-raddest-man.html)
about that much these days, and the mere possibility has to count as a
peculiar life-[circuit](https://news.fastcompany.com/peter-thiel-getting-turned-down-for-a-supreme-court-clerkship-changed-my-life-4008248).

For thermonuclear domestic politics, this one would clearly be hard to
beat.
